Exam Buddy AI

An AI-powered study assistant designed to help students prepare for exams more effectively.

🌐 Live Demo

https://exam-buddy-ai-app-v90y.bolt.host

📖 Problem Statement

Many students struggle to organize their studies, understand difficult topics, prepare quizzes, and stay motivated before exams.

Exam Buddy AI solves this problem by bringing multiple AI-powered study tools together in one simple web application.

👨‍🎓 Target Users

- University Students
- College Students
- Anyone preparing for exams


✨ Features

📅 Study Planner
Creates a personalised study schedule based on subjects, available study days, and exam dates.

❓ Quiz Generator
Generates practice multiple-choice questions on any topic.

💡 Topic Explainer
Explains difficult concepts in simple and easy-to-understand language.

📝 Notes Summariser
Converts long notes into concise summaries with key points.

💪 Study Coach
Provides motivation, productivity tips, and study advice.

🤖 AI Chat
Allows students to ask study-related questions and receive instant AI assistance.


🧠 AI Feature

The application uses Google's Gemini AI to generate personalised educational content.

The AI is instructed to:

- Respond like a friendly study assistant.
- Explain concepts in simple English.
- Generate accurate quizzes.
- Create realistic study plans.
- Summarise notes clearly.
- Motivate students positively.
- Give educational answers only.

🚀 How to Run the Project

1. Clone the repository

git clone https://github.com/sharlawazir/Exam-Buddy-AI.git


2. Install dependencies

npm install


3. Add your Gemini API Key

Create a `.env` file and add:


GEMINI_API_KEY=YOUR_API_KEY


4. Run the application

npm run dev
